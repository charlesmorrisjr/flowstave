# Romantic piano music from the Mutopia Project

These MIDI files were made from Mutopia Project engravings (https://www.mutopiaproject.org, sources from github.com/MutopiaProject/MutopiaProject), compiled with LilyPond 2.25.12 after updating the old syntax with `convert-ly` (plus two manual replacements: `set-octavation` became `\ottava`, and `\applyMusic #unfold-repeats` became `\unfoldRepeats`). The notes are unchanged.

Only original solo piano works marked "Romantic" by Mutopia were taken; arrangements (opera, orchestral and song transcriptions) were left out, as were pieces already in the ASAP dataset. Chopin comes from the Chopin collection instead.

Each file keeps the licence of its source engraving. For the Creative Commons Attribution-ShareAlike files, these MIDI versions are shared under the same licence.
